A 4 KB Python chess engine: iterative-deepening alpha-beta with a transposition table, null-move pruning, late move reductions and quiescence search. It is deterministic (a fixed node budget per move, no clock, no randomness) and makes no model calls.

## Run it

```sh
MAKEFUN_ENV_URL=<env origin> python3 -P -s main.py
```
